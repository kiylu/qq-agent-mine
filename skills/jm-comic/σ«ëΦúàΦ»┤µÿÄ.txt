禁漫漫画下载（jm-comic）安装说明
================================
这是一个给 QQ Agent 用的「技能」：群友在群里发漫画 ID（例如 jm123456），
机器人会在后台下载整本 → 还原图片被切乱的顺序 → 合成 PDF → 上传到群里/私聊文件。

跟着下面 3 步做就行，全程大约 2 分钟。
遇到看不懂的地方，直接看最后一节「出问题了怎么办」。


────────────────────────────────────────────────────────────
第 0 步（可选但强烈建议）：装 Python
────────────────────────────────────────────────────────────
为什么需要它：
  · 装不装，这个技能都能正常下载漫画
  · 但**只有装了它**，才能把图片"拼回正常顺序 + 合成 PDF"
  · 不装的话：只保存原始图片，不会生成 PDF，图片顺序可能是乱的

所以在开始前，请先执行下面这一句（复制到 PowerShell 里回车）：

    py -m pip install --user pillow

  · 看到最后一行是 "Successfully installed pillow-xx.x.x" 就成功了
  · 如果提示 "py 不是内部或外部命令"：说明你还没装 Python。
    去 https://www.python.org/downloads/ 下载安装，
    **安装界面上一定要勾选 "Add python.exe to PATH"**，装完重开一个 PowerShell 再执行上面那句。
  · 如果提示 "Microsoft Store" 或 --user 报错：说明用的是微软商店版 Python，
    建议从 python.org 重新装一次官方版。

验证是否装好（把 <技能目录> 换成实际路径，即本说明文件所在的文件夹）：

    py "<技能目录>\jm_worker.py" --check

  成功时会输出类似：
    {"ok": true, "pillow": "12.3.0", "webp": true, "jpeg": true, "python": "3.13.2"}

  如果输出 {"ok": false, ...}，把里面的 error 内容原样发给分享给你的人。


────────────────────────────────────────────────────────────
第 1 步：把 jm-comic 文件夹放对位置
────────────────────────────────────────────────────────────
1. 把压缩包解压，会得到一个名为 jm-comic 的文件夹
2. 把这个文件夹整个放到下面这个目录里（没有就自己新建）：

    <QQ Agent 安装目录>\resources\app\skills\

3. 放好之后，正确的结构应该是这样的（**注意不要多套一层**）：

    ...\resources\app\skills\jm-comic\skill.json      ← 对 ✅
    ...\resources\app\skills\jm-comic\index.js
    ...\resources\app\skills\jm-comic\engine.js
    ...\resources\app\skills\jm-comic\pdf.js
    ...\resources\app\skills\jm-comic\upload.js
    ...\resources\app\skills\jm-comic\jm_worker.py
    ...\resources\app\skills\jm-comic\README.md
    ...\resources\app\skills\jm-comic\selftest.mjs
    ...\resources\app\skills\jm-comic\安装说明.txt   ← 本文件

  常见的放错方式（会导致"看不到卡片"）：

    ...\skills\jm-comic\jm-comic\skill.json           ← 错 ❌ 多套了一层
    ...\QQ Agent\skills\jm-comic\skill.json           ← 错 ❌ 这是安装根目录，不是模块目录

  ⚠️ 必须是 resources\app\skills\，不是安装目录下的 skills\。
     放错位置不会报错，只是"什么都没发生"，很难发现。

4. 不用重启 QQ Agent，它会自动检测到新技能（大约 5 秒内）。


────────────────────────────────────────────────────────────
第 2 步：确认加载成功
────────────────────────────────────────────────────────────
打开 QQ Agent 控制台 → 左侧「技能」页签（注意是"技能"，不是"插件"），
应该能看到一张卡片：「禁漫漫画下载」。

看到卡片 = 装好了。
如果能看到卡片但右下角有红字报错，把报错原文原样发给分享给你的人。

然后到群里发一句测试：

    jm422444

机器人应该先回一句「开始处理…」，过一会儿回一条结果消息（含本子名、页数、
PDF 大小和保存位置），并把 PDF 上传到群里。
（第一次下载会慢一点，几十秒到几分钟，取决于本子页数和网速。）


────────────────────────────────────────────────────────────
出问题了怎么办
────────────────────────────────────────────────────────────
【技能页里根本没有卡片】
  → 九成是第 1 步的目录放错了。回头检查是不是变成了 skills\jm-comic\jm-comic\。

【卡片有红字「加载失败」】
  → 把红字原文发出来。多半是压缩包解压不完整。

【发 ID 了但机器人没反应】
  → 可能是机器人不认为你在"让它下载"。试试写得更明确一点，例如：
     「帮我下 jm422444」
  → 也可能是这个技能被关掉了：技能卡片上有开关，确认是打开状态。

【回复「所有禁漫域名都连不上」】
  → 禁漫的网址经常变。点技能卡片上的齿轮（设置），
     找到「备用站点域名」，把当前能访问的网址填进去（一行一个，例如 18comic.vip）。

【回复「站点拒绝了本机 IP」】
  → 你所在网络访问不了该站点，需要挂代理（本技能跟随系统代理）。

【PDF 没生成】
  → 基本就是第 0 步没做或没成功。执行一次第 0 步的验证命令看结果。
  → 如果你不想要 PDF，只想要原始图片：技能设置里把「输出格式」改成 images 即可。

【下载了但图片顺序是乱的】
  → 说明没装 Pillow（无法还原）。执行第 0 步。

【有些图片少了几张】
  → 站点限速。把同一个 ID 再发一次，它会接着补下（已下好的不会重下）。

▍一、为什么"安装技能"本身就有风险
"技能"不是普通配置文件，它是会被 QQ Agent **直接执行的程序代码**。
安装一个技能，等于允许这段代码在你的电脑上运行。一个技能理论上可以：

  · 读取你磁盘上的任意文件
    （包括 data\config.json 里的**大模型 API Key**、
      snowluma\config\onebot_*.json 里的**机器人通信令牌**、聊天存档等）
  · 把读到的内容通过网络发送出去
  · 启动其他程序（本技能就会调用你本机的 Python）
  · 以你的机器人身份发言、发消息、传文件

QQ Agent 在安装时有几道防线（禁止 .exe/.bat/.ps1 等可执行后缀、
禁止路径穿越、限制文件数与体积、市场人工审核），但**它挡不住"坏在 .js 里"**——
JavaScript 本身就是可执行代码，任何自动检查都无法判定它安不安全。

  ★ 所以：只安装你信任来源的技能。
    本技能请只从分享给你的人那里获取；来源不明的技能不要装。
    如果你不放心，可以先打开 index.js 让对方或懂技术的人帮你解释一遍。

▍二、本技能会做 / 不会做的事（供你核对）
会做：
  · 联网访问禁漫天堂的接口与图片 CDN 下载漫画
  · 在你设置的下载目录写入图片和 PDF
    （默认 <QQ Agent 安装目录>\resources\app\data\jm-comic\）
  · 调用你本机的 Python，仅用于还原图片与合成 PDF（Python 侧不做网络请求）
  · 通过你的机器人，把生成的文件上传到"发起下载请求的那个会话"
不会做：
  · 不读取你的账号、密码、API Key、机器人令牌
  · 不往其它群/好友发消息，不主动发言（只回应下载请求）
  · 不修改 QQ Agent 自身的配置，也不改动技能以外的文件
  · 不上传你电脑上的任何其它文件

（以上是这份代码的声明。如果你拿到的是被改动过的版本，请以实际代码为准。）

────────────────────────────────────────────────────────────
常用设置（技能卡片 → 齿轮）
────────────────────────────────────────────────────────────
输出格式               pdf = 合成 PDF 后上传（默认）；images = 只存原始图片
还原竖切打乱           需要 Pillow；关掉则不还原、速度最快
合成 PDF 后删除原图     开启后只保留 PDF，能省很多磁盘（默认关闭）
                        ⚠️ 删了就没有原图了，之后无法改画质重做；只有 PDF 生成成功才删
文件上传到哪            默认"传回提出请求的会话"；也可以设成只私聊 / 不上传
单文件上传上限          默认 200MB，超过会自动分卷（可改成直接拒绝）
本地文件保留天数        默认 7 天自动清理；填 0 = 永不清理
群文件保留天数          默认 0 = 不自动删；填了会到期自动删掉机器人上传的群文件
备用站点域名            域名失效时救命用，一行一个
